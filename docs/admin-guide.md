# 홈페이지 관리자 사용 안내

관리 주소는 `/admin`입니다. 일반 홈페이지 방문자는 가입할 필요가 없습니다.

포트폴리오 방문자는 로그인 화면에 표시되는 체험 계정의 아이디·비밀번호를 복사하거나 `체험 계정으로 바로 로그인`을 누르면 됩니다. 체험 계정은 관리자 화면과 기존 콘텐츠를 볼 수 있지만 저장, 삭제, 순서 변경, 사진 업로드는 할 수 없습니다.

1. **로그인 신청:** `Google로 계속하기` 또는 `일반 가입으로 진행`을 선택합니다. 처음 가입한 계정은 승인 대기가 되고, 최고 관리자가 승인하면 관리 기능을 사용합니다. 일반 가입은 이름·이메일·8자 이상 비밀번호를 사용합니다.
2. **뉴스:** 뉴스 관리 → 뉴스 등록 → 제목·날짜·사진 입력 → 오른쪽 카드 미리보기 확인 → 임시 저장 또는 홈페이지에 올리기. 대표 뉴스는 한 건만 지정됩니다. 원문 기사 주소는 선택 사항입니다.
3. **크리에이터:** 크리에이터 → 등록 → 이름·표시 이름·카테고리·구독자 표시·사진 입력 → 미리보기 → 홈페이지에 올리기. 사진 초점과 채널 주소는 선택 항목에서 편집합니다. 표시 순서 변경에서 끌기 또는 위·아래 버튼을 사용한 뒤 순서를 저장합니다.
4. **사진:** 새 사진을 올리거나 기존 사진 선택에서 재사용합니다. JPEG/PNG/WebP/AVIF, 10MB 이하입니다. 콘텐츠에서 사용하는 사진은 삭제되지 않습니다.
5. **수정·숨김·복원:** 수정 내용 반영을 누르면 공개 페이지의 다음 조회에 반영됩니다. 숨김은 홈페이지에서만 내립니다. 삭제는 휴지통 이동이며 상태 필터를 휴지통으로 바꾸면 복원할 수 있습니다. 복원은 임시 저장 상태이므로 다시 확인한 뒤 게시합니다.
6. **동시 편집:** 다른 직원이 먼저 저장했다는 안내가 나오면 목록에서 다시 열어 최신 내용을 확인하세요.
7. **직원 관리:** 최고 관리자만 Google·일반 가입 신청을 승인·거절·정지·재활성화할 수 있습니다. 정지한 계정은 기존 로그인도 해제됩니다. 최고 관리자 이전은 Google이 이메일을 확인한 승인 직원에게만 가능합니다.
8. **최초 최고 관리자:** 서버의 `INITIAL_OWNER_EMAIL`에 지정한 Google 계정이 처음 로그인하면 자동으로 최고 관리자가 됩니다. 일반 가입 계정은 최초 최고 관리자를 자동 선점할 수 없습니다.
9. **체험 계정:** `npm run db:import`가 공개용 `DEMO` 계정을 준비합니다. 포트폴리오 검토자가 뉴스·크리에이터·사진·직원·변경 기록 등 최고 관리자 기능을 직접 시험할 수 있으며, 서비스 소유권 이전만 제한됩니다.

내용을 바꿀 때 코드 수정이나 서버 재배포는 필요하지 않습니다. 메인/MCN 영상 자체는 크리에이터 등록으로 바뀌지 않습니다. 파트너·인터뷰·F&B·행사 편집은 2차 범위입니다.
